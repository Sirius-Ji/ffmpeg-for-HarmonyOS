# x86_64 模拟器下载与验收

## GUI 下载（用户执行）

1. 打开 DevEco Studio → **Tools** → **Device Manager**。
2. 选择 **Local Emulator** 标签。
3. 点 **Install** / **+** 创建模拟器。
4. API 选与项目匹配的版本；系统镜像选 **x86_64**（不要选 arm64）。
5. 记下镜像下载目录（通常在 DevEco 的 emulator/SDK 目录下）。
6. 启动 AVD。

## 下载完成后 DSH 执行

```bash
# 1. 找 target
"D:/Program Files/DevEco Studio/sdk/default/openharmony/toolchains/hdc.exe" list targets
# 2. 确认 ABI 必须是 x86_64
hdc -t <target> shell getprop ro.product.cpu.abi
# 3. 安装并打开
TARGET=<target> bash build/verify-x86_64.sh
# 4. 在平板/模拟器点 ASS Style 审计、SRT force 审计，拉回 audit_ass/audit_srt_1x。
```

验收标准：ASS 三 Style、SRT force 四组、字幕/PiP 时间轴与 arm64 一致；截帧文件名带 `abi=x86_64`。
