# v0.3.0 API 草稿（V03-12）

状态：草稿，未实现；旧 API 保持不变。

## 1. 兼容策略

- 旧入口 `videoTranscode(src, dst, format, resolution, volume, imagePath[, optionsJson])` 继续可用；
- 新入口建议独立方法 `videoTranscodePlan(src, dst, planJson)`，避免把旧 `watermark|...` 字符串继续扩展；
- `optionsJson` 作为过渡层保留，旧字段（`trimStart/trimEnd/cropW/...`）继续解析；
- 不删除/不改语义现有字段。

## 3. 语义约定

- `trim`/`pip`/`subtitle` 的时间都按**输出时间轴**解释；实现用 `filter_pts = trim_relative_ms / speed`。
- `rotate` 只对图片水印生效；文字水印只支持任意坐标，不支持旋转。
- 旧字符串参数与 `optionsJson` 并存时，旧显式参数优先；新 `videoTranscodePlan` 只读 JSON。
- 失败策略：字幕文件不存在时跳过字幕并保留转码；缺失字体由 libass fallback；不因字幕崩掉整条转码。
